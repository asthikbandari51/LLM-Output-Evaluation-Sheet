## Why I Built This

Most people applying for AI data annotation roles list skills on a résumé.
I wanted to *demonstrate* those skills instead.

This project replicates exactly what professional annotators do for AI
training data clients: collect model outputs, apply a structured scoring
rubric, identify failure patterns, and write justified findings. I built
it independently to show I understand not just *what* annotation is,
but *why* human judgment is irreplaceable in LLM quality evaluation —
and where each model actually breaks down.
